DS1202 Project

Overview

This project contains a Bash script called "sysinfo.sh" that displays basic system information.

Directory Structure

- "scripts/" - Contains the system information script.
- "docs/" - Stores project documentation.
- "logs/" - Stores system information logs.

Features

- Displays the hostname.
- Displays the kernel version.
- Displays memory usage.
- Records system information in a log file.

How to Run

Run the following commands in the terminal:

cd ~/ds1202-project
./scripts/sysinfo.sh

Technologies Used

- Ubuntu Linux
- Bash scripting
- Git and GitHub
- SSH
